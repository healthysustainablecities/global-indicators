** This folder contains a subset of the DejaVu fonts, specifically, the 'Sans Condensed' variety that are used by default when generating reports.  For some languages, in particular those with non-latin scripts, alternative fonts may need to be sourced and configured.  See the `fonts` workshet in the _report_configuration.xlsx work book for example configurations and URLs from which fonts could be sourced **

The bundled [Vazirmatn](https://github.com/rastikerdar/vazirmatn) fonts (`vazirmatn-v33.003/`) are used for Persian and Arabic reports; they cover Arabic presentation forms, diacritics (harakat), Persian digits, the zero-width non-joiner and Latin text.  How right-to-left text rendering works, and how to configure fonts for another right-to-left language, is documented in [process/subprocesses/RTL_RENDERING.md](../../subprocesses/RTL_RENDERING.md).
